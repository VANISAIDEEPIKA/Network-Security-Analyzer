# Network Security Analyzer


The **Network Security Analyzer** is a web-based cybersecurity application developed to monitor, analyze, and classify network traffic using Machine Learning. The system captures live network packets, extracts key traffic features, and detects malicious activities in real time using a **Random Forest Classifier**.

The application provides an interactive dashboard for network monitoring, attack detection, forensic analysis, and visualization, making it suitable for both academic learning and cybersecurity research.

---

## Features

- Real-time network traffic monitoring
- Live packet capture and feature extraction
- Machine Learning-based attack detection
- Detection of multiple network attack types
- Interactive Streamlit dashboard
- Attack simulation using Nmap
- Security status visualization
- Network log analysis and reporting
- Performance metrics and statistical visualizations
- Forensic explanations with recommended mitigation strategies

## Supported Attack Detection

The system is capable of detecting and analyzing attacks such as:

- SYN Flood
- UDP Flood
- HTTP Flood
- Port Scanning
- SSH Brute Force
- ARP Spoofing
- Data Exfiltration

---

## Project Workflow

1. Capture live network traffic.
2. Extract network traffic features.
3. Preprocess captured packet data.
4. Predict network activity using the Random Forest model.
5. Classify network traffic as normal or malicious.
6. Display security status and attack information.
7. Visualize results through interactive dashboards.
8. Generate forensic reports and mitigation recommendations.
